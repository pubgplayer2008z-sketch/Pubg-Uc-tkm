# PubgUc Tkm — Minimal Gaming Pricing Site

What this is:
- A small, mobile-friendly one-page layout with a bold pill-shaped header, a left-aligned "Bahalar…" title, and three yellow pricing cards.
- Each pricing card is clickable and points to its own page: `30uc.html`, `60uc.html`, and `325uc-vip.html`.

Files:
- `index.html` — landing / prices overview
- `styles.css` — shared styles (fonts, layout, glow effects)
- `30uc.html`, `60uc.html`, `325uc-vip.html` — individual product pages

How to view locally:
1. Download these files into a folder.
2. Open `index.html` in your browser (double-click or use a local file server).
3. Click a card to open its page.

To deploy to GitHub Pages:
1. Create a repository (or use your existing one).
2. Push these files to the repository root (or `gh-pages` branch).
3. Enable GitHub Pages in repo settings and point it to the branch/folder containing `index.html`.
